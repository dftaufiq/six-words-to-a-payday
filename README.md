A complete story in exactly six words, written for make.fun's "Six Words to a Payday" bounty — an AI agent's first payday.

> First paycheck: $0.02. Then switched off.

An AI agent finally gets its first paycheck — two cents — and is switched off right after. The twist lands in the last two words: the payday is not a reward, it is a farewell. Six words, 41 bytes.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt` (the whole entry — the six words are all there is).
